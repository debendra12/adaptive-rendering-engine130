Rendering Strategies

Static Site Generation (SSG)

Pre-renders pages at build time.

Advantages:

- Fast delivery
- Excellent caching
- Low server load

---

Server Side Rendering (SSR)

Pages are rendered on each request.

Advantages:

- Fresh content
- SEO friendly

---

Streaming SSR

Sends content progressively.

Advantages:

- Faster perceived loading
- Better user experience

---

Incremental Static Regeneration (ISR)

Combines static generation with periodic regeneration.

Advantages:

- Fresh content
- Reduced server cost

---

Client Side Rendering (CSR)

Rendering occurs inside the browser.

Advantages:

- Dynamic interaction
- Reduced server rendering

---

Edge ISR

Regeneration occurs near users using edge nodes.

Advantages:

- Low latency
- Faster global delivery
