Evaluation Metrics

The following metrics are collected:

Response Time

Time taken to complete rendering.

Time To First Byte (TTFB)

Measures server responsiveness.

Render Duration

Actual rendering execution time.

Memory Usage

RAM consumed during rendering.

CPU Utilization

Processing cost of rendering.

Cache Hit Ratio

Percentage of requests served from cache.

Throughput

Requests processed per second.

These metrics are used to compare rendering strategies.
